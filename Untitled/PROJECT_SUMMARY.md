## 💡 Animation Patterns Used

### 1. **Entrance Animations**
```
Fade + Slide: opacity and transform simultaneously
Duration: 0.5s - 0.6s
Stagger: 0.05s - 0.1s between items
```

### 2. **Scroll Animations**
```
WhileInView: animations trigger as user scrolls
Viewport Once: animations play only once
Duration: 0.6s smooth transitions
```

### 3. **Hover Interactions**
```
Scale: 1.05x - 1.1x on hover
Color: Opacity changes on interaction
Duration: 0.2s - 0.3s snappy response
```

### 4. **Progressive Loading**
```
Staggered delays create cascade effect
First item: 0s delay
Each next item: +0.05s/0.1s delay
Total visible within 0.5s - 1.0s
```
